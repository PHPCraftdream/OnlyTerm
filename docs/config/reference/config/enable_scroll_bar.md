# `enable_scroll_bar`

Enable the scrollbar.  OnlyTerm enables this by default.
It will occupy the right window padding space.

If right padding is set to 0 then it will be increased to 1.75 cell widths
(wide enough for the thumb to stay easy to see and grab).

```rhai
config.enable_scroll_bar = true
```
