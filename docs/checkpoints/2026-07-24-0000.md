любой найденный баг/недочёт (включая ошибки в собственной работе агентов)

## Decisions

- Полностью удалить SSH-клиент и TLS-mux вместо миграции на russh — russh
  тоже тянет C/asm крипто-ядро (ring/aws-lc-rs), ценность фичи для
  пользователя ("нужен просто быстрый локальный терминал") не оправдывала
  сохранение C-зависимости ради неё.
- rhai выбран вместо чистого поиска Lua-совместимого движка — `piccolo`
  (чистый Rust Lua-VM) признан слишком незрелым (v0.3.x, 10% документации)
  для роли конфиг-движка продукта; принят осознанный breaking change формата
  конфига.
- Для интеграции rhai-конверсий выбран подход "параллельный макрос"
  (`impl_rhai_conversion_dynamic!`) вместо переделки `impl_lua_conversion_dynamic!`
  в backend-agnostic — mlua-трейты параметризованы по лайфтайму `Lua`-инстанса,
  у rhai::Dynamic такого нет, единый макрос дублировал бы тело почти целиком.
- Параллельные агенты — только через `isolation: 'worktree'` или строго
  последовательно, никогда параллельно в общем рабочем дереве (правило
  появилось после реального конфликта незакоммиченных изменений от
  нескольких агентов одновременно).
- При обнаружении бага/недочёта — сразу заводить таску и чинить на месте,
  не откладывать (явное правило пользователя, применялось 7+ раз за сессию).
