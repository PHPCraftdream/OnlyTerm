## Decisions
- Always pipe `crush run` prompts via a temp file + `< /dev/null`-safe stdin redirect (`crush run ... < prompt.txt`), never as an inline quoted Bash argument — inline quoting broke once (UP-13) on a large prompt containing embedded code/quotes.
- Never let two `crush` invocations touch the same working tree concurrently, even accidentally via an incompletely-killed orphan process — this caused a near-miss duplicate-const collision on UP-01. `taskkill //F //T` is not fully trustworthy for killing the actual crush subprocess; the real fix was moving to sequential-only execution in the shared root (no worktrees) per the user's explicit instruction, which removes the parallelism risk entirely as long as I don't launch a new `crush run` before confirming the previous one's process is gone.
- Fixed `wezterm-gui/build.rs`'s hardcoded `<repo>/target/<profile>` myself directly (not delegated) because it was a 2-minute mechanical fix blocking dozens of downstream tasks — derived the correct dir from `OUT_DIR` ancestors instead, which is `CARGO_TARGET_DIR`-agnostic.
- For platform-gated fixes (macOS/X11/Wayland/Unix-only files) that cannot be compiled or tested on this Windows machine: copy the upstream diff **literally**, do not attempt to "improve" it, and always add an explicit, honest disclosure in the task's final summary distinguishing verified (cross-platform, tested here) vs. copied-blind (platform-gated, unverifiable here) portions.
- UP-20: deliberately skipped PR #7548 in favor of PR #7966, because both open PRs address the same Wayland tiled-window-state gap with mutually exclusive designs and #7966's dedicated `WindowState::TILED` bitflag is strictly more correct than #7548's "conflate tiled with maximized" approach.
- UP-17 had no upstream PR at all (issue #6499 only) — diagnosed the panic mechanism (`&ext[1..]` on an empty PATHEXT segment from a stray `;;`) myself from the issue text + source read, and had `crush` implement an original fix (`strip_prefix('.')` guard) rather than a diff-based cherry-pick.
