## Decisions
- chose `MemoryHints::MemoryUsage` over keeping `Performance`: the dump showed ~1 GiB reserved for ~30 MB of data.
- chose a GUI process with no GPU device (CPU atlas mirror, lazy buffers, adapter from the child) over a device-only
  context: it drew nothing but held ~80 MB plus the GPU driver, and kept the GUI process exposed to driver faults.
- chose frame latency 1 only for the hosted child's composition surface (in-process fallback keeps 2): saves one
  window-sized buffer (8 / 15 / 33 MB at 1080p / 1440p / 4K) per window; one-line revert in `desired_frame_latency`.
- chose 12.5% headroom + release above 1.5x for the instance pool over power-of-two / 4x; accepted trade-off: a request that
  swings down by more than 1.5x and back up can recreate the buffer.
- chose merge commits for the PRs (history stays valid for dependent branches) and CI-only verification for everything.
