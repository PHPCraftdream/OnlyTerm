## Decisions
- chose pinning the Windows CI toolchain to 1.99.1 over shortening the build dir or dropping sccache: a shorter build dir only fits `onlyterm-gpu-render` (onlyterm-gui has more transitive deps and would exceed 32767 again), and without sccache builds lose ~1500 of 1650 cache hits.
- chose `i128::from(n).try_into()` over `#[allow(unreachable_code)]` in `int!`: the conversion stays fallible for every target type, error text unchanged.
- chose the version tag `v0.0.44-alpha` pushed on the user's request (publishes a release); the displayed version is tag-derived, Cargo.toml `0.1.0` is unused and left alone.
- chose PrintWindow + posted messages (WM_NCACTIVATE/ACTIVATE/SETFOCUS) for screenshots over screen copy and real foreground focus: no leak of other windows, no stolen focus; the title shows CPU/RAM only after two samples in a "focused" window.
- chose to keep attribution to WezTerm/Wez (README, license) while removing support/community links and `wezterm.org` links from code and docs.
