## Decisions

1. Принять PF-4 64-KiB budget, отклонить 16-KiB prototype; сохранить UTF/grapheme/NFC, queries/backpressure/DEC 2026 и resize/snapshot дисциплину. Budget soft: indivisible grapheme и descheduling не дают hard wall-time guarantee.
2. Принять PF-5 только с целевым lifecycle доказательством; не переносить процент ускорения на весь GUI/TUI.
3. Не зачесть PF-2/PF-3/PF-6 performance alternatives: отрицательные результаты/шумный контроль не являются выигрышем. Production scanner/reflow algorithms оставлены прежними, кроме correctness fixes.
4. Profiler opt-in; queue/row count metrics не считать duration, nested timers не суммировать в critical path, GPU submission CPU time не называть GPU execution. Allocation и physical-pixel latency не измерялись.
5. Не завершать пользовательские OnlyTerm процессы и не менять домашний .onlyterm.ktav. Только собственные GUI PID, лично захваченные при запуске, могли закрываться harness.
