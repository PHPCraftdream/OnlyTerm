## Decisions
- При входе `crush` в час-пик (08:00–12:00, подтверждено сообщением провайдера) — переключение на `@sh`-агентов по заранее данной пользователем инструкции; будильник на 12:00 для обратного переключения был поставлен, но не понадобился — пользователь остановил работу раньше явной командой.
- Для Tier-1 задач без готового апстрим-PR — методология "честный тройной исход" (реальный точечный фикс / NO-OP с regression-тестом, если баг уже закрыт / NO-FIX-WARRANTED с детальным анализом, если нет уверенности в механизме) вместо принудительного придумывания фикса любой ценой.
- UP-37 (Wayland window_decorations): решено НЕ реализовывать более правильный "реактивный" фикс (чтение granted decoration_mode из configure-события), так как апстрим уже пробовал именно это (commit `0c97ace3c`) и откатил (`e5ac32f29`) из-за краша под Weston — слепое повторение без реального Wayland-стенда для проверки признано слишком рискованным.
- UP-40 (scroll wheel): выбран cap `MAX_WHEEL_TICKS = 128` на магнитуду свайпа как защита от одного экстремального значения от драйвера, спамящего pty тысячами событий — обоснованное консервативное решение, не найдено существующего аналогичного капа в кодовой базе для переиспользования.
- Задачи #124–#130 (побочные пользовательские запросы) зарегистрированы в TaskList, но НЕ выполнялись в этой сессии — явно оставлены "на потом" по формулировкам пользователя ("давай потом", "заведи таску под это").
