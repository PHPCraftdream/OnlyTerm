`text_min_contrast_respects_hidden_text` (default false), and -- after the user proposed

`reduced_col` instead of `increased_col` (copy-paste). Committed as `66fc423c5`.

## Decisions

- Tab-title cwd tracks the pty's root process, not the tree's "youngest" process --
  deliberately breaks the (undesired) behavior of following an embedded agent's own
  subshell navigation.

  (opt back in via `text_min_contrast_respects_hidden_text`), and fix them by
  substituting the theme's own default fg/bg pair rather than nudging via OKLAB

  explicitly preserve LICENSE.md, `authors=`, and build.rs CompanyName/LegalCopyright

  the "Wez"/"Wez (Gogh)" third-party color schemes and the upstream-changelog copy;
  re-namespace AppUserModelID/MyAppPublisher to the fork's own identity.

  active there -- and it paid off: codex's own commit landed on `origin/main` mid-session
