- CI-паковка: Windows получает полностью переименованные `onlyterm*` бинарники/инсталлятор; Linux/macOS собирают из `onlyterm*`-исходника, но пакуют/устанавливают под старым именем `onlyterm*` — чтобы не каскадировать непроверяемые (на этой Windows-машине) правки desktop-интеграции на других ОС.
