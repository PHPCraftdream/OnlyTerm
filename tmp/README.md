# tmp

Рабочий каталог для одноразовых артефактов: скрипты-пробы, временные
конфиги, скриншоты, перехваченные логи.

Всё содержимое, кроме этого файла, игнорируется гитом (`/tmp/` в
`.gitignore`). Ничего важного здесь держать нельзя — каталог считается
расходным и может быть очищен в любой момент.

Правило: никакие временные файлы не создаются за пределами репозитория.
